# Тезисы — Автоматическая подготовка тезисов к проектным совещаниям

## Что это

Инструмент анализа план-графиков строительства (.mpp) и автоматической генерации структурированных текстовых отчётов (тезисов) для проектных совещаний. Два режима: «до РНС» и «СМР».

## Бизнес-контекст

MR Group (строительный девелопмент). По каждому проекту регулярно проводятся совещания. Подготовка тезисов вручную занимает много времени. Макрос формирует готовый отчёт по утверждённым чек-листам одним нажатием.

## Стек

```
Python 3.8+ → JPype1 → JVM (JDK 17) → MPXJ → .mpp файлы
openpyxl — чтение Excel (если нужно)
Jinja2 — шаблоны текстовых отчётов
```

## Родственные проекты

- **Проверка/** — базовая аналитика .mpp (отклонения, каскады, технологическая последовательность). Код можно переиспользовать.
- **PermitFlow/** — чтение .mpp, предиктивная модель ГПЗУ-РНС, эталонные варианты графиков.

## Архитектура (план)

```
Тезисы/
├── read_mpp.py            # Чтение .mpp (из Проверки, адаптированный)
├── analyzer.py            # Расширенная аналитика: отклонения, группировка по корпусам/зонам,
│                          #   критические задачи, % завершения, резервы, опережение
├── thesis_generator.py    # Генерация текстовых тезисов по шаблонам чек-листов
├── decisions.py           # Автоматические управленческие решения (правила)
├── checklists/            # Чек-листы в структурированном формате
│   ├── rns.yaml           # Чек-лист «до РНС»
│   └── smr.yaml           # Чек-лист «СМР»
├── templates/             # Jinja2-шаблоны отчётов
│   ├── report_rns.md      # Шаблон отчёта РНС
│   └── report_smr.md      # Шаблон отчёта СМР
├── main.py                # Точка входа: режим, путь к .mpp → готовый отчёт
├── requirements.txt
└── CLAUDE.md
```

## Два режима

| Режим | Когда | Фокус |
|-------|-------|-------|
| **РНС** | До получения разрешения на строительство | Разрешительная документация, согласования, ГПЗУ, ППТ |
| **СМР** | Строительно-монтажные работы | Отклонения от графика, критический путь, ресурсы, МПТ |

## Использование (целевое)

```bash
pip install -r requirements.txt

# Режим СМР
python main.py "график.mpp" --mode smr

# Режим РНС
python main.py "график.mpp" --mode rns

# С указанием выходного файла
python main.py "график.mpp" --mode smr -o тезисы_совещание.md
```

## Ключевые аналитические блоки

1. Декомпозиция отклонений по корпусам/зонам
2. Критические задачи с низким % завершения
3. Каскадное влияние сдвигов
4. Зоны опережения и временного резерва
5. Обязательства по МПТ
6. Зоны неопределённости
7. Управленческие решения (переброска ресурсов, запросы на согласование, компенсационные мероприятия)
